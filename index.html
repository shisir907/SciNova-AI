About SciNova AI Platform

SciNova AI is an all-in-one web-based science learning hub designed to make STEM education accessible, interactive, and engaging for curious minds.

Shipaton 2026 Context

Built during RevenueCat’s Shipaton 2026 global hackathon hosted on Devpost (Submissions closing 1 Oct 2026 @ 12:30 PM GMT+5:45). It aligns with the challenge of building real, functional tools for actual users.

Web Architecture & Engineering

Developed using lightweight single-file HTML/CSS/JS architecture, integrating MapLibre GL for satellite geospatial rendering and OpenRouter API endpoints for real-time natural language query processing.

Founder & Solo Developer

Designed, programmed, tested, and shipped end-to-end as a complete web solution.

Project Overview

SciNova AI combines conversational AI, global scientific headlines, and satellite geospatial mapping inside a unified web environment, making scientific inquiry effortless.

Core Web Features Built
  • AI Science Chat: Custom system-prompted LLM specialized exclusively in answering STEM, astronomy, and technology questions.
  • Curated News Feed: Real-time international science headlines and research breakthroughs updated for September 2026.
  • MapLibre Interactive Map: High-resolution hybrid satellite tiles with touch-enabled coordinate pinpointing.
  • Mobile-Optimized UI: Responsive, dark-themed interface built for seamless browsing on any mobile or desktop web browser.
